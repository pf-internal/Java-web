【問題2】　Servlet で setAttribute したキー名と、JSP で取り出すキー名が一致している必要があります。⑤〜⑦に入る語を答えてください。

// ItemListServlet.java（doGet）

【問題3】　「データの通り道マップ」の①〜⑥に入る語を語群から選んでください。

JSTL（c:out / c:forEach / c:if）を使った表示パターンを完成させましょう。

【問題4】　商品一覧を表示する JSP コードの A〜D に入るタグ・属性・値を答えてください。

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<table border="1">
  <tr>
    <th>ID</th><th>商品名</th><th>価格</th>

  <A var="B" items="${itemList}">

      <td><c:out value="${C.itemId}"/></td>

A は繰り返しのタグ名（c:???）。B はループ変数名。C は B で宣言した変数名。D は値を安全に出力するタグ（XSS対策）。

B: item
C: item   ← var="item" で宣言した変数名と同じ

【問題5】　ログインしているときだけ「ようこそ」メッセージを出す JSP の E〜G に入る語を答えてください。

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<E test="${F != null}">
    <p>ようこそ、<c:out value="${G}"/> さん！</p>
</c:if>

※ Servlet 側で session.setAttribute("loginUser", userName); を実行済みとします。

【問題6】　次の JSP コードについて、正しいものを選んでください（複数可）。

（ア）<c:out value="${item.itemName}"/>
（イ）<c:forEach var="item" items="${items}" begin="1">
（ウ）<c:if test="${msg != null}">${msg}</c:if>
（エ）<c:forEach items="${itemList}">${item.price}</c:forEach>

発展：doPost を完成させる（商品登録 Servlet）

商品登録 Servlet の doPost メソッドを完成させましょう。A〜H に入る語を答えてください。

@WebServlet("/item/register")
public class ItemRegisterServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {

        request.setCharacterEncoding("UTF-8");

        // ① フォームから値を取得
        String itemName = request.A("itemName");
        String priceStr = request.getParameter("price");
        int price = Integer.B(priceStr);

        // ② DTO に詰める
        C dto = new ItemDto();
        dto.setItemName(D);
        dto.setPrice(price);

        // ③ DAOで登録
        ItemDao dao = new ItemDao();
        int result = dao.E(dto);

        // ④ 完了メッセージをセットして一覧にリダイレクト
        if (result > 0) {
            request.F("message", "登録が完了しました");
        }
        response.G(request.getContextPath() + "H");
    }
}
ヒント①（A〜D）

A は文字列パラメータを取得するメソッド名。B は文字列を int に変換する静的メソッド名。C は DTO のクラス名。D はローカル変数 itemName。

ヒント②（E〜H）

E は DAOの登録メソッド名。F は request にキーと値をセットするメソッド。G は別URLへリダイレクトするメソッド。H は一覧画面の URL パス（例：/item/list）。

解答例

【解説・確認用】

A: getParameter
B: parseInt
C: ItemDto
D: itemName   ← ローカル変数をそのまま渡す
E: insert
F: setAttribute
G: sendRedirect
H: /item/list （例）
