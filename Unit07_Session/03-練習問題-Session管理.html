ミッション1：HttpSession 操作の穴埋め

【問題1-1】 次のログイン処理の（ ① 〜 ④ ）を埋めてください。

// ① Session を取得（なければ新規作成）
HttpSession session = request.（ ① ）();

// ② ログインユーザー名を Session に保存
session.（ ② ）("loginUser", userName);

// ③ Session からログインユーザー名を取り出す
String loginUser = （ ③ ） session.（ ④ ）("loginUser");
ヒント
  • ① request から Session を取得するメソッド名
  • ② 値を保存するメソッド（request.setAttribute と同じ形）
  • ③ getAttribute の戻り値は Object 型 → キャストが必要
  • ④ 値を取り出すメソッド（request.getAttribute と同じ形）
解答例 
① getSession
② setAttribute
③ (String)
④ getAttribute

ミッション3：ログイン状態管理フローの穴埋め

【問題3-1】 次の「ログイン → 認証 → 状態保存 → 次ページで確認」フローの（ ① 〜 ⑤ ）を埋めてください。

【LoginServlet の doPost】

String password = request.getParameter("password");

// DB で認証（例：DAOで照合）

if (isValid) {
	// ① Session を取得して userId を保存
	HttpSession session = request.（ ① ）();
	session.（ ② ）("loginUserId", userId);

	// ③ 認証成功 → メニュー画面にリダイレクト
	response.sendRedirect(request.getContextPath() + "/menu");
} else {
	// 認証失敗 → エラーを request に入れてログイン画面に戻す
	request.（ ③ ）("errorMsg", "IDまたはパスワードが違います");
	request.getRequestDispatcher("/WEB-INF/jsp/login.jsp")
	       .（ ④ ）(request, response);
}

【MenuServlet の doGet】（ログイン済みチェック）
HttpSession session = request.getSession(false);
if (session == null || session.getAttribute("loginUserId") == null) {
	// Session がない or loginUserId がない → ログイン画面に戻す
	response.sendRedirect(request.getContextPath() + "/login");
	return;
}
String loginUserId = （ ⑤ ） session.getAttribute("loginUserId");
ヒント①

  • ② は値を保存するメソッド
ヒント②

  • ④ は JSP に処理を移すメソッド
  • ⑤ は String 型へのキャスト
解答例 
① getSession
② setAttribute
③ setAttribute
④ forward
