チャプター1：JSP の正体

JSP は見た目は HTML に近いですが、Tomcat が自動的に Servlet の Java コードに変換してからコンパイル・実行します。

JSP の記法 意味 例
<%= 式 %> 値を画面に出力する <%= item.getName() %>
<% 文 %> Java のコードを書く（スクリプトレット） <% for (Item item : items) { %>
${ 式 } EL式（より簡潔に値を出力） ${item.name}

カバ先生：「Unit09 以降は JSTL（c:forEach 等）前提になります。スクリプトレット（<% %>）は仕組みを理解するために学びますが、実際には使わずに JSTL に置き換えていきます。」

チャプター2：JavaBeans のルール

JSP や JSTL がデータを扱いやすくするために、JavaBeans という「形が決まった Java クラス」を使います。

JavaBeans の3つのルール

  • 引数なしのコンストラクタがある
  • フィールドは private、外部からは getter / setter でアクセスする
  • getter の名前は get + フィールド名（先頭大文字）
public class ItemDto {

	// フィールド（private）
	private int    itemId;
	private String itemName;
	private int    price;

	// 引数なしのコンストラクタ（必須）
	public ItemDto() {}

	// getter / setter
	public int getItemId() {
		return itemId;
	}
	public void setItemId(int itemId) {
		this.itemId = itemId;
	}
	public String getItemName() {
		return itemName;
	}
	public void setItemName(String itemName) {
		this.itemName = itemName;
	}
	public int getPrice() {
		return price;
	}
	public void setPrice(int price) {
		this.price = price;
	}
}

カバ先生：EL 式で ${item.itemName} と書くと、内部では自動的に item.getItemName() が呼ばれます。getter の名前の形が決まっているから EL 式がフィールド名から自動でメソッドを見つけられます。これが JavaBeans のルールに従う理由です。

チャプター3：JSPでの表示パターン（スクリプトレット → JSTL）

3-1. 単一値の表示

スクリプトレット版（仕組みを理解する用）

<p>登録完了：<%= message %></p>

JSTL版（実際の開発で使う）

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<p>登録完了：<c:out value="${message}"/></p>

3-2. 一覧表示（List を table で展開）

スクリプトレット版

<table border="1">
  <tr><th>ID</th><th>商品名</th><th>価格</th></tr>
  <% for (ItemDto item : items) { %>
    <tr>
      <td><%= item.getItemId() %></td>
      <td><%= item.getItemName() %></td>
      <td><%= item.getPrice() %></td>
    </tr>
  <% } %>
</table>

JSTL版（Unit09 以降はこちらが前提）

<table border="1">
  <tr><th>ID</th><th>商品名</th><th>価格</th></tr>
  <c:forEach var="item" items="${items}">
    <tr>
      <td><c:out value="${item.itemId}"/></td>
      <td><c:out value="${item.itemName}"/></td>
      <td><c:out value="${item.price}"/></td>
    </tr>
  </c:forEach>
</table>

3-3. 条件分岐（メッセージの出し分け）

JSTL版

<c:if test="${not empty message}">
  <p style="color: green;"><c:out value="${message}"/></p>
</c:if>

<c:if test="${not empty errorMsg}">
  <p style="color: red;"><c:out value="${errorMsg}"/></p>
</c:if>
JSTLタグ 役割 スクリプトレットの置き換え
c:out 値を安全に出力（XSS対策） <%= %>
c:forEach コレクションをループ <% for (...) { %>
c:if 条件分岐（else なし） <% if (...) { %>

まとめ

  • JSP は最終的に Servlet に変換されて実行される。ファイルは .jsp だが中身は Java
  • JavaBeans のルール：引数なしコンストラクタ ＋ private フィールド ＋ getter/setter
  • EL 式 ${item.itemName} は内部で item.getItemName() を呼ぶ
  • JSTL の最小3タグ：c:out（出力）／ c:forEach（ループ）／ c:if（条件）
  • Unit09 以降は JSTL 前提。スクリプトレットは仕組み理解のみ
