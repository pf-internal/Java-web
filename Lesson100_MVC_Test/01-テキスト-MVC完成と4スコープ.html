チャプター1：MVCの三角形と役割分担

MVC とは何か

カバ先生： MVCは「役割を3つに分けるルール」です。

コードが全部1か所に書いてあると、後から読めなくなります。

そこで「受け取る人（C）・処理する人（M）・表示する人（V）」に分業します。

役割 担当クラス やること
Controller（C） Servlet リクエスト受け取り・判断・フォワード
Model（M） DAO / JavaBeans（DTO） データ操作（SQL）・ビジネスロジック
View（V） JSP 画面表示（HTMLを組み立てる）

ユウタ： Servlet に全部書いたらダメなんですか？

カバ先生： 動きはします。でも SQL と HTML が混在したコードは、後から修正する時に大変です。「JSP には表示だけ、DAOにはSQLだけ」と決めておくと、変更箇所を1か所で済ませられます。

ルール：何を書いてはいけないか

ファイル 書いてよいこと 書いてはいけないこと
Servlet getParameter / setAttribute / forward / sendRedirect SQL文・HTMLの直接出力
DAO SQL / JDBC / ResultSet処理 request / response の操作
JSP EL式 / JSTL / HTMLタグ DB接続・ビジネスロジック

チャプター2：フォルダ構成の型

「どこに何を置くか」を決めておくと、チームで開発するときに迷いません。

基本のフォルダ構成（Eclipse Dynamic Web Project）

myapp/
  src/
    main/
      java/
        controller/       ← Servlet（Controller）
            ItemListServlet.java
            ItemRegisterServlet.java
        model/            ← DAO / DTO（Model）
            ItemDao.java
            ItemDto.java
  webapp/
    WEB-INF/
      jsp/              ← JSPファイル（View）※直接アクセス不可
          itemList.jsp
          itemRegister.jsp
      web.xml
    assets/            ← CSS・画像（任意）
    index.jsp          ← トップページ（任意）

ナナコ： なんで JSP は WEB-INF の中にあるんですか？

カバ先生： WEB-INF/ はブラウザから直接アクセスできないフォルダです。JSP を直接叩かれると Servlet を経由しないためデータが空になります。「必ず Servlet を通してから表示する」ように WEB-INF/jsp/ に置くのがお作法です。

1機能の紐づけ型

機能 URL Servlet DAO JSP
一覧表示 /item/list ItemListServlet findAll() itemList.jsp
新規登録 /item/register ItemRegisterServlet insert(dto) itemRegister.jsp
詳細表示 /item/detail ItemDetailServlet findById(id) itemDetail.jsp

「1機能 = 1URL + 1Servlet + 1DAOメソッド + 1JSP」が基本の型です。

チャプター3：4スコープの使い分け（寿命表）

スコープ オブジェクト 寿命 使いどき（例）
page pageContext JSP の1ページ内だけ ほぼ使わない
request HttpServletRequest 1回のリクエスト〜レスポンス 一覧データ・エラーメッセージ・完了メッセージ
session HttpSession ブラウザを閉じるまで（またはinvalidate） ログインユーザー・カート情報
application ServletContext Tomcat起動〜停止 サイト全体の設定値・アクセスカウンタ

ユウタ： session に全部入れたらダメですか？

カバ先生： session はサーバのメモリを消費し続けます。「1回の画面遷移で済む情報」は request に入れ、「ブラウザをまたいで必要な情報」だけ session にしましょう。迷ったら 寿命の短いほうを選ぶのが鉄則です。

スコープの操作コード例

// request スコープ（Servlet → JSP への一時的な橋渡し）
request.setAttribute("itemList", itemList);
RequestDispatcher dispatcher =
    request.getRequestDispatcher("/WEB-INF/jsp/itemList.jsp");
dispatcher.forward(request, response);

// session スコープ（ログイン情報の保持）
HttpSession session = request.getSession();
session.setAttribute("loginUser", userName);

// application スコープ（サーバ全体の共有値）
ServletContext application = getServletContext();
application.setAttribute("siteTitle", "商品管理システム");
