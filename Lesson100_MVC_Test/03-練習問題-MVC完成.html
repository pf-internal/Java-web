ミッション3：4スコープ使い分け問題

次のデータを保持するのに最適なスコープ（request / session / application）を選んでください。

データ 理由（選ぶポイント） スコープ
登録完了メッセージ
（「登録しました」）		 次の1画面だけ使えれば十分 ①
ログイン中のユーザー名 複数ページをまたいで表示する ②
商品一覧（Listオブジェクト） Servlet から JSP へ1回だけ渡す ③

寿命の短い順に：request（1回のやりとり）→ session（ブラウザ単位）→ application（サーバ全体）。迷ったら寿命の短いほうを選ぶのが原則です。

解答例

【解説・確認用】

① request     ← 1回の画面遷移だけに使う
② session     ← 複数ページをまたいで保持
③ request     ← Servlet → JSP の橋渡し
④ session     ← 購入完了（または invalidate）まで保持
⑤ application ← 全ユーザー共通・サーバ全体で1つ

ミッション4：間違いはどこ？（MVCルール違反）

次のコードには MVC のルール違反が含まれています。どこが問題か指摘してください。

【問題A】　次の JSP コードの問題点を答えてください。

<!-- itemList.jsp -->
<%
    Connection con = DriverManager.getConnection(URL, USER, PASS);
    PreparedStatement ps = con.prepareStatement("SELECT * FROM items");
    ResultSet rs = ps.executeQuery();
    List<ItemDto> list = new ArrayList<>();
    while (rs.next()) {
        ItemDto dto = new ItemDto();
        dto.setItemId(rs.getInt("id"));
        list.add(dto);
    }
%>
<c:forEach var="item" items="${list}">
    <c:out value="${item.itemId}"/>
</c:forEach>
ヒント

JSP（View）は表示だけを担当します。ここに書いてある処理は本来どのクラスが行うべきでしょうか？

解答例

【解説・確認用】

問題点：JSP の中に DB 接続（JDBC）と SQL 処理が書かれている。

正しいやり方：
  ・DB接続・SQL実行は ItemDao（Model）に移す
  ・Servlet（Controller）で dao.findAll() を呼び、結果を request.setAttribute する
  ・JSP（View）は ${itemList} を c:forEach で表示するだけにする

【問題B】　次の Servlet コードの問題点を答えてください。

// ItemListServlet.java（doGet）
protected void doGet(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {

    List<ItemDto> itemList = dao.findAll();
    request.setAttribute("itemList", itemList);

    // JSP に HTML を直接 out で書いてしまっている
    PrintWriter out = response.getWriter();
    out.println("<html><body>");
    for (ItemDto item : itemList) {
        out.println("<p>" + item.getItemName() + "</p>");
    }
    out.println("</body></html>");
}
ヒント

Servlet（Controller）が HTML を直接出力しています。HTML の組み立ては誰の仕事でしょうか？

解答例

【解説・確認用】

問題点：Servlet（Controller）が HTML を out.println で直接出力している。

正しいやり方：
  ・HTML の出力は JSP（View）に任せる
  ・Servlet は setAttribute してから forward するだけにする

// 修正例
request.setAttribute("itemList", itemList);
RequestDispatcher dispatcher =
    request.getRequestDispatcher("/WEB-INF/jsp/itemList.jsp");
dispatcher.forward(request, response);
