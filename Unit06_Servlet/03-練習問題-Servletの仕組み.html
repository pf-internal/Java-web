ミッション1：getParameter の穴埋め

【問題1-1】 次のフォームと Servlet のコードがあります。（ ① 〜 ③ ）に入る語句を答えてください。

【フォーム（HTML）】

<form action="/myapp/register" method="post">
  <input type="text"   name="memberName">
  <input type="number" name="age">
  <button type="submit">登録</button>
</form>

【Servlet の doPost】

String name   = request.getParameter（ ① ）;
String ageStr = request.getParameter（ ② ）;
int    age    = Integer.（ ③ ）(ageStr);
ヒント
  • ① と ② の引数はフォームの name 属性の値と完全一致させる
  • ③ は String を int に変換するメソッド名（Integer クラスのメソッド）
解答例 
① ("memberName")
② ("age")
③ parseInt

【問題1-2】 次のうち、getParameter が null を返す原因として正しいものをすべて選んでください。

  • A. フォームの name 属性と getParameter の引数の文字列が一致していない
  • B. 入力フィールドに何も入力せずに送信した（空文字）
  • C. フォームの method を "get" にしたまま doPost で受けようとしている
  • D. getParameter に存在しないキー名を指定した
解答例

正解：A と D

  • A：キー名の不一致 → null が返る（最も多いバグの原因）
  • B：空文字は null ではなく ""（空文字列）が返る
  • C：doPost ではなく doGet が呼ばれてしまう。getParameter 自体は呼ばれない（または doPost に到達しない）
  • D：存在しないキーを指定すると null が返る

ミッション2：setAttribute のキー名統一問題

【問題2-1】 次の Servlet と JSP のコードがあります。JSP で一覧を正しく表示するために、（ ① ）〜（ ③ ）に入るキー名を答えてください。キー名はすべて同じ文字列である必要があります。

【Servlet の doGet】

List<MemberDto> memberList = dao.findAll();
request.setAttribute（ ① ）, memberList);

【JSP（memberList.jsp）】

<%
  List<MemberDto> memberList =
      (List<MemberDto>) request.getAttribute（ ② ）);
  for (MemberDto m : memberList) {
%>
  <tr><td><%= m.getMemberName() %></td></tr>
<% } %>

【JSTL 版 JSP（参考）】

<c:forEach var="m" items="${（ ③ ）}">
  <tr><td><c:out value="${m.memberName}"/></td></tr>
</c:forEach>
ヒント

① ② ③ はすべて同じキー文字列です。setAttribute で保存したキー名を、getAttribute と EL 式 ${...} の両方で使います。

解答例 
① ("members"   // ← 自分でキー名を決める（memberList でも OK）
② ("members"   // ① と同じ文字列
③  members     // EL 式では ${members} → ① と同じ文字列

※ キー名は自由に決めてよいが、Servlet と JSP で必ず一致させること

ミッション3：データの通り道マップ穴埋め

【問題3-1】 次の「データの通り道マップ」の（ ① 〜 ⑦ ）に入る語句を答えてください。

【フォーム（HTML）】
  name="（ ① ）"  ←→  name="（ ② ）"

          ↓ POSTリクエスト

【Servlet の doPost】
  request.（ ③ ）("（ ① ）")  ← フォームの name と一致
  request.（ ③ ）("（ ② ）")  ← フォームの name と一致
          ↓ 型変換 → DTO に詰める → （ ④ ）.insert(dto)

【Servlet の doGet】
  （ ④ ）.findAll()  ← DB から取得
  request.（ ⑤ ）("items", itemList)  ← JSP に渡すキー名
  （ ⑥ ）.forward(request, response)  ← JSP へ移動

          ↓

【JSP】
  ${（ ⑦ ）}  ← ⑤ で指定したキー名と一致
記号 自分の解答 ヒント
① 商品名フィールドのname属性値（例：itemName）
② 価格フィールドのname属性値（例：price）
③ フォームの値を取り出すメソッド名
④ DB操作を担当するクラスの変数名（例：dao）
⑤ JSPにデータを預けるメソッド名
⑥ JSPへ処理を移すオブジェクト名（例：dispatcher）
⑦ ⑤ で指定したキー文字列と一致する
ヒント①（メソッド名だけ）
  • ③ は getParameter
  • ⑤ は setAttribute
  • ⑥ は dispatcher
解答例 
① itemName        （フォームの name 属性の値）
② price           （フォームの name 属性の値）
③ getParameter    （値を取り出すメソッド）
④ dao             （DAO のインスタンス変数名）
⑤ setAttribute    （JSP へ渡すメソッド）
⑥ dispatcher      （RequestDispatcher のインスタンス変数名）
⑦ items           （⑤ の第1引数のキー文字列と一致）

発展：Servlet の doPost を完成させる

【発展問題】 次のコードは「商品名と価格をフォームから受け取り、DBに登録する」doPost です。（ A 〜 G ）を埋めて完成させてください。

@Override
protected void doPost(HttpServletRequest request, HttpServletResponse response)
		throws ServletException, IOException {

	// ① フォームの値を受け取る
	String itemName = request.（ A ）("itemName");
	String priceStr = request.（ A ）("price");

	// ② 型変換
	int price = Integer.（ B ）(priceStr);

	// ③ DTO に詰める
	ItemDto dto = new （ C ）();
	dto.setItemName(（ D ）);
	dto.setPrice(（ E ）);

	// ④ DAO に登録を依頼
	ItemDao dao = new ItemDao();
	dao.（ F ）(dto);

	// ⑤ 一覧画面にリダイレクト
	response.（ G ）(request.getContextPath() + "/items");
}
ヒント①（型と変数名）
  • A は getParameter、B は parseInt
  • C は DTO クラス名、D・E はローカル変数名
ヒント②（DAOとリダイレクト）
  • F は DAO の登録メソッド名（Unit04 で作ったもの）
  • G は POST後に一覧へ戻るための sendRedirect
解答例 
A → getParameter
B → parseInt
C → ItemDto
D → itemName
E → price
F → insert
G → sendRedirect
