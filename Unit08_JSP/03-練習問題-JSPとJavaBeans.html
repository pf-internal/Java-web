ミッション1：getter 呼び出しの穴埋め

【問題1-1】 次の MemberDto クラスに対して、JSP で値を表示するコードの（ ① 〜 ③ ）を埋めてください。

【MemberDto の定義（抜粋）】

public class MemberDto {
	private int    memberId;
	private String memberName;
	private String email;

	public int    getMemberId()   { return memberId; }
	public String getMemberName() { return memberName; }
	public String getEmail()      { return email; }
	// setter は省略
}

【スクリプトレット版 JSP の穴埋め】

<% for (MemberDto m : members) { %>
  <tr>
    <td><%= m.get（ ① ）() %></td>
    <td><%= m.get（ ② ）() %></td>
    <td><%= m.get（ ③ ）() %></td>
  </tr>
<% } %>

【JSTL版 JSP の穴埋め（EL式）】

<c:forEach var="m" items="${members}">
  <tr>
    <td><c:out value="${m.（ ① ）}"/></td>
    <td><c:out value="${m.（ ② ）}"/></td>
    <td><c:out value="${m.（ ③ ）}"/></td>
  </tr>
</c:forEach>
ヒント

スクリプトレット版の get（①）() は getter メソッド名の get を除いた部分（先頭大文字）。EL式版の ${m.①} はフィールド名（先頭小文字）を使います。

解答例 
【スクリプトレット版】
① MemberId    → m.getMemberId()
② MemberName  → m.getMemberName()
③ Email       → m.getEmail()

【EL式版】
① memberId    → ${m.memberId}
② memberName  → ${m.memberName}
③ email       → ${m.email}

ミッション2：c:forEach の型穴埋め

【問題2-1】 次の c:forEach の（ A 〜 C ）に入る語句を答えてください。

<c:forEach （ A ）="item" （ B ）="${（ C ）}">
  <tr>
    <td><c:out value="${item.itemName}"/></td>
  </tr>
</c:forEach>
記号 意味 ヒント
A ループ変数名を指定する属性
B コレクション（List）を指定する属性
C Servlet が setAttribute("○○", itemList) で渡したキー名
解答例 
A → var    （ループ変数名の指定）
B → items  （コレクションの指定）
C → items  （Servlet の setAttribute のキー名と一致させる）

完成形：
<c:forEach var="item" items="${items}">
  <tr>
    <td><c:out value="${item.itemName}"/></td>
  </tr>
</c:forEach>

【問題2-2】 次の説明のうち正しいものを選んでください。

  • A. c:forEach の var に指定した名前は、JSP ファイル内でだけ使えるループ変数である
  • B. c:forEach の items に指定するのは Servlet の setAttribute で渡したキー名と無関係でよい
  • C. c:out は XSS 対策のためにHTMLの特殊文字をエスケープしてくれる
  • D. c:if には else に相当するタグが存在しない（else を書くには c:choose を使う）
解答例

正解：A と C と D

  • A：var の名前はそのループ内だけで使えるローカル変数
  • B：誤り。${items} の "items" は Servlet の setAttribute("items", ...) と一致させる必要がある
  • C：c:out は < → &lt; などに変換してXSS対策になる
  • D：c:if に else はない。else が必要なら c:choose / c:when / c:otherwise を使う

ミッション3：JSP 表示パズル

【問題3-1】 次の Servlet のコードを見て、JSP の（ ① 〜 ④ ）を埋めて完成させてください。

【Servlet の doGet】

ItemDao dao = new ItemDao();
List<ItemDto> itemList = dao.findAll();
request.setAttribute("itemList", itemList);
request.setAttribute("pageTitle", "商品一覧");
request.getRequestDispatcher("/WEB-INF/jsp/itemList.jsp")
       .forward(request, response);

【itemList.jsp の穴埋め】

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<h1><c:out value="${（ ① ）}"/></h1>

<table border="1">
  <tr><th>ID</th><th>商品名</th><th>価格</th></tr>
  <c:forEach var="item" items="${（ ② ）}">
    <tr>
      <td><c:out value="${item.（ ③ ）}"/></td>
      <td><c:out value="${item.（ ④ ）}"/></td>
      <td><c:out value="${item.price}"/></td>
    </tr>
  </c:forEach>
</table>
ヒント

① ② は Servlet の setAttribute のキー名と一致させます。③ ④ は ItemDto のフィールド名（先頭小文字）です。

解答例 
① pageTitle    （setAttribute("pageTitle", "商品一覧") のキー）
② itemList     （setAttribute("itemList", itemList) のキー）
③ itemId       （ItemDto の getItemId() → EL式では itemId）
④ itemName     （ItemDto の getItemName() → EL式では itemName）
