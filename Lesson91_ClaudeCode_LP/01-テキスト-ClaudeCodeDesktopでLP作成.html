1. Claude Code とは

Claude Code は、Anthropic 社が開発した AI アシスタント「Claude」を使って、会話形式でファイル・コードを作れるツールです。

普通の AI チャットとの違い

ChatGPT・Claude.ai（普通のチャット） Claude Code Desktop
出力 テキスト・コードを「表示」するだけ PC 上のファイルに直接書き出し
操作 コードをコピーして自分で貼る 「○○を修正して」で即反映
向いている用途 質問・調査・アイデア出し LP・アプリ・ツールの実制作

カバ先生：「簡単に言うと、『AI がキーボードを代わりに打ってくれる』イメージです。あなたは指示を出すだけで、Claude Code がファイルを作り・書き・直してくれます。」

ユウタ：「プログラムを書かなくていいんですか？」

カバ先生：「書かなくて OK。でも、何を作りたいかを伝える力 は必要です。今日はその『伝え方』を一緒に練習しましょう。」

ナナコ：「Cursor と似ていますか？」

カバ先生：「Cursor も AI を使ってコードを書くツールですが、Cursor はコードエディタ（プログラムを書く専用ソフト）に AI を組み込んだもの。Claude Code は、ファイルを直接操作する AI エージェントです。指示の出し方・作業の進み方が少し異なりますが、今日のようなLP作成なら Claude Code の方がシンプルに扱えます。」

【図】Claude Code の全体像：「あなたの指示 → Claude Code → PC上のファイル生成・編集 → ブラウザで確認」の流れを示す図

3-2. 指示の出し方（プロンプトの書き方）

Claude Code への指示（プロンプト）は、「何を・どのように・どんな条件で」 を伝えると精度が上がります。

良いプロンプト vs 曖昧なプロンプト

曖昧な指示（うまくいかない例） 具体的な指示（うまくいく例）
「かっこいい LP を作って」 「カフェの LP を HTML で作って。ヘッダー・キャッチコピー・メニュー3点・地図のセクション・フッターを含めてください。」
「色を変えて」 「ヘッダーの背景色を #2c3e50（濃紺）、文字色を白に変えてください。」
「もっとよくして」 「ボタンのデザインを角丸にして、ホバー時に背景色が少し明るくなるようにしてください。」

カバ先生：「プロンプトは『お客さんに仕様書を渡す』感覚で書いてください。誰が読んでも同じものが作れるレベルの情報量が理想です。」

ユウタ：「一発でうまくいかなかったときはどうするんですか？」

カバ先生：「気にせず『○○の部分だけ直して』と追加で指示します。AI との作業は対話です。一発完成を目指す必要はありません。」

プロンプトの型（コピーして使ってください）

【目的】○○のLP を HTML ファイル（index.html）で作成してください。
【対象】○○を探している人
【構成】ヘッダー / キャッチコピー / サービス紹介（3項目）/ CTA ボタン / フッター
【デザイン】シンプル・白基調・アクセントカラーは青系
【その他】スマートフォンでも見やすいレスポンシブ対応

4. LP の設計：ゴールと構成を決める

ハンズオンに入る前に、「何のための LP か」 を決めます。ここを曖昧にすると、AI への指示も曖昧になります。

LP とは（Landing Page）

  • 検索や広告から最初にたどり着く「1枚もの」のウェブページ
  • 目的は 1つだけ（問い合わせ・予約・購入など）
  • 余計なリンクがなく、訪問者を1つの行動へ誘導する構成

LP の基本構成（テンプレート）

ヘッダー（ロゴ・ナビ）
ヒーローセクション
キャッチコピー ＋ サブコピー ＋ CTA ボタン
サービス・特徴の紹介（3〜4 項目）
お客様の声 / 実績（信頼構築）
料金・プラン
CTA セクション（問い合わせ・予約ボタン）
フッター

設計シート（今日作る LP を書き込みましょう）

項目 記入欄
LP のテーマ 例：英語スクールの体験レッスン申込み LP
ターゲット 例：30代・仕事で英語が必要になった方
ゴール（1つ） 例：「無料体験申込み」ボタンをクリックさせる
キャッチコピー 例：「3ヶ月で会議英語が話せるようになる」
特徴・強み（3つ） 例：①マンツーマン ②朝6時から夜23時 ③業種別コース
デザインイメージ 例：シンプル・白基調・アクセントは青

5-2. ハンズオン：見た目を整える（40分）

土台ができたら、細部を調整します。一度に大きく変えず、1つずつ確認しながら進めるのがコツです。

よく使う調整プロンプト例

やりたいこと プロンプト例
色を変える 「CTA ボタンの色を #e74c3c（赤）に変えてください。」
フォントを変える 「見出しのフォントを Google Fonts の Noto Sans JP にしてください。」
スペースを調整 「各セクションの上下余白を広くして、読みやすくしてください。」

5-4. スキルを使ってさらにパワーアップ

Claude Code には スキル という仕組みがあります。スキルとは、よく使う作業を「ひとこと」で呼び出せるようにパッケージ化した機能です。チャット欄で /スキル名 と入力するだけで動きます。

ユウタ：「スキルって、どんなものがあるんですか？」

カバ先生：「たとえると、料理のレシピカードのようなものです。『カレーを作れ』と言う代わりに、レシピカードを渡す感じです。よく使う手順が1枚にまとまっているので、毎回一から説明しなくて済みます。」

ナナコ：「LP 作りで使えるスキルって、具体的にどんなものですか？」

LP・アプリ作りで役立つスキル一覧

スキル名 できること LP 作りでの活用例
/pdf PDF の作成・変換・結合・分割 完成した LP の内容を提案書 PDF に変換して納品
/pptx PowerPoint スライドの作成・編集 LP の企画・構成をクライアントへのプレゼン資料にまとめる
/docx Word 文書の作成・編集 LP のコピーライティング原稿・仕様書を Word で出力
/xlsx Excel スプレッドシートの作成・編集 お問い合わせ数・CVR を管理する集計シートを自動生成
/run アプリを起動してブラウザで動作確認 LP をローカルサーバーで動かして表示チェック
/verify 変更が正しく反映されているか自動検証 「修正したけど本当に直っているか不安」なときに確認を任せる

スキルの使い方（実際の操作）

チャット欄にスラッシュ（/）を入力すると、使えるスキルの一覧が表示されます。

【図】チャット欄に「/」を入力したときのスキル候補一覧の表示例

例：LP を PDF に変換したいとき

/pdf
index.html の内容を A4 縦の PDF（lp-proposal.pdf）に変換してください。

上級者向け：自分専用スキルを作れる

よく繰り返す作業は /skill-creator スキルを使うと、自分だけのオリジナルスキルとして登録できます。

  • 例：「うちのブランドカラーで LP を作るスキル」
  • 例：「お客様の声セクションを3件追加するスキル」
  • 例：「SEO 向けのメタタグを自動設定するスキル」

カバ先生：「スキルは一度作るとチームで共有もできます。『この作業、毎回同じことやってるな』と感じたら、スキル化のチャンスです。」

体験：PDF スキルを使ってみよう（クリックで開く）

完成した LP を PDF に変換する体験をしてみましょう。

STEP 1：チャット欄に次のように入力します。

/pdf
index.html を PDF（A4縦・ファイル名は lp-output.pdf）に変換してください。

STEP 2：生成された lp-output.pdf を開いて、LP の内容が正しく出力されているか確認します。

→ これだけで、クライアントに送れる提案書 PDF が完成します。
