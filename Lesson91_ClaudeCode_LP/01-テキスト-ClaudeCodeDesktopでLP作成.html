1　Claude Code とは

ChatGPT・Gemini・Claude などは「チャットボット型AI」と呼ばれ、質問に対して 1問1答 で答えを返してくれます。

一方、Claude Code は、あなたが許可した範囲で、あなたに 代わってPCを操作 してくれるサービスです。ファイルを作る・直す、アプリを動かすといった作業を代行します。

許可した範囲については、優秀な秘書が仕事をこなしておいてくれるイメージです。

アイデアを形にするまでの道のりが、短くなった

普通のAIチャットClaude Code Desktop
出力コードを「表示」するだけPCのファイルに直接書き出し
操作コードをコピーして自分で貼る「○○を修正して」で即反映
拡張性チャット内のみMCP でブラウザ・外部アプリと連携

答えを見せるだけか、PCのファイルまで直接作るか

カバ先生

簡単に言うと「AI がキーボードを代わりに打ってくれる」イメージです。さらに MCP を組み合わせると、ブラウザやアプリまで任せられます。ここまでの説明に、イメージのズレがなければ、さっそく体験していきましょう。

2　MCP とは：AI がアプリに仕事を頼む「窓口」

MCP（Model Context Protocol） は、Claude がブラウザ・Slack・データベースなど、PCの外のアプリとやり取りするための 共通の「窓口」 です。

アプリの窓口に「これをやっておいて」と依頼すると、アプリが仕事をやってくれて、必要があれば結果を渡してくれます。MCP を使うと、Claude Code はいろいろなサービスにこうして仕事を頼めるようになります。

MCP は、アプリに仕事を頼む共通の窓口

Claude in ChromeChrome ブラウザをAIが直接操作。フォーム入力・ボタンクリック・スクリーンショット撮影を自動化
Slack MCPSlack へのメッセージ送信・チャンネル検索・通知自動化
GitHub MCPPR 作成・コードレビュー依頼・Issue 管理を AI が代行

2-1. Claude in Chrome：ブラウザを AI が操作する

Chrome 拡張機能「Claude in Chrome」を入れると、Claude Code がブラウザを直接コントロールできます。

指示の例

今開いているフォームに以下の情報を入力して送信してください：
名前：山田太郎、メール：test@example.com、お問い合わせ内容：テスト送信
このページのスクリーンショットを撮って、商品一覧の価格をCSVにまとめてください

従来の自動化（Selenium 等）との違い

従来ツール（Selenium など）MCP（Claude in Chrome）
画面変更への対応HTML 構造が変わるとスクリプトが壊れるAIが意味で理解するため変更に強い
セットアップコード（XPath/CSSセレクタ）を書く必要がある日本語で指示するだけ
仕様変更対応スクリプトを書き直す工数がかかる指示をそのまま再実行するだけで OK

カバ先生

Selenium のような自動化ツールは、ページの HTML 構造が変わった途端に壊れます。MCP は AI が「ボタンがどこにあるか」を見た目と文脈で判断するので、仕様変更・デザインリニューアルが起きても 同じ指示で動き続ける のが大きな強みです。

3　環境構築

前提：Git のインストール

Claude Code はファイル管理に Git を使うため、先にインストールが必要です。

Windows
git-scm.com を開き「Download for Windows」→ インストーラーを実行（オプションはすべてデフォルトで OK）→ コマンドプロンプトで git --version と入力してバージョンが表示されれば完了
Mac
ターミナルで git --version を実行 → インストールを促すダイアログが出たら「インストール」を押すだけで完了（Xcode コマンドラインツールとして自動インストールされます）

※ すでに Git が入っている場合は git --version でバージョンが表示されるのでスキップして OK

インストールの手順

1ダウンロード：claude.ai/code を開き「Download」
2インストール：Windows は .exe をダブルクリック／Mac は .dmg をアプリフォルダへドラッグ
3API キー発行：console.anthropic.com でアカウント作成 → Billing にカード登録 → 「API Keys」→「Create Key」
4ログイン：Claude Code Desktop を起動 → 「API Key でサインイン」→ キーを貼り付け
5動作確認：デスクトップに my-lp フォルダを作成 → Claude Code で開き、「hello.txt を作って『動作確認OK』と書いて」と入力
Windows の警告
「詳細情報」→「実行」
Mac の警告
システム設定 → セキュリティ →「このまま開く」
料金目安
