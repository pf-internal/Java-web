1. Claude Code とは

Claude Code は、AI「Claude」を使って 会話形式でファイル・コードを作れるツールです。普通のAIチャットとの最大の違いは、テキストを「表示する」だけでなく PC上のファイルに直接書き出し・編集できる点です。

普通のAIチャット Claude Code Desktop
出力 コードを「表示」するだけ PCのファイルに直接書き出し
操作 コードをコピーして自分で貼る 「○○を修正して」で即反映
拡張性 チャット内のみ MCP でブラウザ・外部アプリと連携

カバ先生：「簡単に言うと『AI がキーボードを代わりに打ってくれる』イメージです。さらに MCP を組み合わせると、ブラウザやアプリまで操作できるようになります。」

2. MCP とは：AI にツールの「手」を持たせる仕組み

MCP（Model Context Protocol） は、Claude がブラウザ・アプリ・データベースなど外部ツールと連携するための 共通の「接続口」 です。MCP を使うと、Claude Code はPCの外に出て様々なサービスを直接操作できます。

MCP でできること（代表例）

MCP ツール できること
Claude in Chrome Chrome ブラウザをAIが直接操作。フォーム入力・ボタンクリック・スクリーンショット撮影を自動化
Slack MCP Slack へのメッセージ送信・チャンネル検索・通知自動化
GitHub MCP PR 作成・コードレビュー依頼・Issue 管理を AI が代行
Google Drive MCP ファイル検索・ドキュメント読み取り・スプレッドシート更新
データベース MCP SQL を AI が生成・実行。自然言語でデータを取得・集計

2-1. Claude in Chrome：ブラウザを AI が操作する

Chrome 拡張機能「Claude in Chrome」を入れると、Claude Code がブラウザを直接コントロールできます。

指示の例

今開いているフォームに以下の情報を入力して送信してください：
名前：山田太郎、メール：test@example.com、お問い合わせ内容：テスト送信
このページのスクリーンショットを撮って、商品一覧の価格をCSVにまとめてください

従来の自動化（Selenium 等）との違い

従来ツール（Selenium など） MCP（Claude in Chrome）
画面変更への対応 HTML 構造が変わるとスクリプトが壊れる AIが意味で理解するため変更に強い
セットアップ コード（XPath/CSSセレクタ）を書く必要がある 日本語で指示するだけ
仕様変更対応 スクリプトを書き直す工数がかかる 指示をそのまま再実行するだけで OK

カバ先生：「Selenium のような自動化ツールは、ページの HTML 構造が変わった途端に壊れます。MCP は AI が『ボタンがどこにあるか』を見た目と文脈で判断するので、仕様変更・デザインリニューアルが起きても 同じ指示で動き続ける のが大きな強みです。」

2-2. アプリケーション自動化の実例

やりたいこと Claude への指示例

3. 環境構築

前提：Git のインストール

Claude Code はファイル管理に Git を使うため、先にインストールが必要です。

OS 手順
Windows git-scm.com を開き「Download for Windows」→ インストーラーを実行（オプションはすべてデフォルトで OK）→ コマンドプロンプトで git --version と入力してバージョンが表示されれば完了
Mac ターミナルで git --version を実行 → インストールを促すダイアログが出たら「インストール」を押すだけで完了（Xcode コマンドラインツールとして自動インストールされます）

※ すでに Git が入っている場合は git --version でバージョンが表示されるのでスキップして OK

手順

  1. ダウンロード：claude.ai/code を開き「Download」
  2. インストール：Windows は .exe をダブルクリック／Mac は .dmg をアプリフォルダへドラッグ
  3. API キー発行：console.anthropic.com でアカウント作成 → Billing にカード登録 → 「API Keys」→「Create Key」
  4. ログイン：Claude Code Desktop を起動 → 「API Key でサインイン」→ キーを貼り付け
  5. 動作確認：デスクトップに my-lp フォルダを作成 → Claude Code で開き、「hello.txt を作って『動作確認OK』と書いて」と入力
Windows の警告：「詳細情報」→「実行」
Mac の警告：システム設定 → セキュリティ →「このまま開く」
料金目安：今日の演習で $1〜2 程度
