# 特別講義 Claude Code Desktop で仕事・ビジネスを加速する 図解（8枚・1節＝スライド1枚）

これは、特別講義「Claude Code Desktop で仕事・ビジネスを加速する」（約4時間・PC基本操作ができる方向け）のテキストに載せる図解の台本です。
「## 図n」から次の「## 図」までが、スライド1枚ぶんの内容です。1つの見出し＝1枚のスライドとして図解してください。
見出しをまたいで内容を混ぜたり、1枚に複数の見出しをまとめたりしないでください。表紙・目次・まとめのスライドは不要です。
各節の「ねらい」が、そのスライドで伝えたい要点1つです。図の中心にはこれを置いてください。
「対比」と書かれている項目は左右に並べて比較できる形で、「順序」と書かれている項目は左から右への流れで図解してください。
文字はすべて日本語で、スライド内の文字は短く（1要素あたり10文字前後）にしてください。英語の見出し・ラベルは入れないでください。

---

## 図1 作りたいものを、AIに話しかけて形にする時代

**ねらい:** 以前は、アイデアを形にするには何人もの専門家と長い時間が必要だった。いまは日本語で指示するだけで、自分のPCの中で形になる。（対比）

- 上段「これまで」＝左に「アイデア」、右に「完成品」。間に「デザイナー」「フロントエンド」「バックエンド」「公開作業」の4つの箱が絡まった線で結ばれ、「何カ月も」というラベル
- 下段「いま」＝左に「アイデア」、右に「完成品」。まっすぐな1本の線で結ばれ、中央に「Claude Code に日本語で指示」というラベル、「数分〜数時間」
- 上段は線がごちゃごちゃ、下段はすっきり、という差が一目で分かるようにする

---

## 図2 ふつうのAIチャットと Claude Code Desktop のちがい

**ねらい:** ふつうのAIチャットは答えを「表示する」だけ。Claude Code は、PCのファイルに直接書き出し、修正まで反映する。（対比）

- 左に「ふつうのAIチャット」、右に「Claude Code Desktop」の2枚のカードを並べる。右のカードを強調する
- 行1「出力」＝左「コードを表示するだけ」／右「PCのファイルに直接書き出し」
- 行2「操作」＝左「コピーして自分で貼る」／右「『直して』で即反映」
- 行3「広がり」＝左「チャットの中だけ」／右「ブラウザやアプリとも連携」
- 右カードの中央に「PCの中に住むAIアシスタント」という小さな見出しと、フォルダ・ターミナル・ブラウザの3つのアイコンを置く

---

## 図3 MCP は、AIに「手」を持たせる共通の接続口

**ねらい:** MCP は、Claude が外のツール（ブラウザ・チャット・資料・データ）とつながるための共通の差し込み口。つなぐほど、できる仕事が増える。（構造）

- 中央に「Claude」を表す丸いブロックを置く
- 中央から5方向へ線を伸ばし、5つのツールを配置する
- ツール1「Chrome」＝ブラウザを操作（フォーム入力・画面撮影）
- ツール2「Slack」＝メッセージ送信・通知
- ツール3「GitHub」＝レビュー依頼・課題管理
- ツール4「Google ドライブ」＝ファイル検索・資料の読み取り
- ツール5「データベース」＝日本語でデータを取得・集計
- 線の途中に小さく「MCP」と書いた差し込み口のアイコンを置く

---

## 図4 壁打ちは「投げる → 見る → 直す」のくり返し

**ねらい:** 完璧な指示を作る必要はない。ざっくり投げて、見て、気になる点を直す。これをくり返して形にする。（順序・循環）

- 4つのステップを円環に配置する
- ステップ1「投げる」＝ざっくり指示
- ステップ2「見る」＝ブラウザで確認
- ステップ3「直す」＝気になる点を指示
- ステップ4「くり返す」＝完成まで
- ステップ4からステップ1へ矢印を戻して、何度も回ることを示す
- 中央に「完璧でなくていい」という短いラベル

---

## 図5 今日の4時間の流れ

**ねらい:** 環境構築から始め、LPづくりで対話の基本を身につけ、ビジネス活用まで進む。ハンズオンが全体の約8割。（順序・時間軸）

- 左から右へ、横長のタイムラインにする。5つの区間
- 区間1「0:00〜0:30」＝Claude Code・MCP とは／環境構築
- 区間2「0:30〜1:00」＝MCP 体験（Chrome 自動化・アプリ連携）
- 区間3「1:00〜2:00」＝ハンズオン①　壁打ちでLPを完成させる。目立たせる
- 区間4「2:00〜3:30」＝ハンズオン②　ビジネス活用（リサーチ・自動化・ビジネスモデル分析）。いちばん太く、目立たせる
- 区間5「3:30〜4:00」＝まとめ・次のステップ
- 区間3と4の上に「ここが主役（ハンズオン）」の吹き出し

## 図6 伝わる指示の型：誰に・何を・どんな雰囲気で・何を載せるか

**ねらい:** あいまいな指示はあいまいな結果になる。作るものを4つの要素に分けて、最初の一投に入れる。（構造）

- 中央に「最初の一投」と書いた、メッセージ吹き出しの大きなカード
- 吹き出しから4方向に、4つの要素カードを配置する
- 要素1「テーマ」＝何のページか（例：英語スクールの体験申込み）
- 要素2「ターゲット」＝誰に向けるか（例：30代・仕事で英語が必要な人）
- 要素3「コピーと強み」＝キャッチコピーと特徴3つ
- 要素4「見た目」＝色・雰囲気・スマホ対応（例：白基調でシンプル）
- 下に小さく「足りない所は、あとから壁打ちで足す」

---

## 図7 Claude Code を使いこなす3つのコツ

**ねらい:** AIは心を読む魔法使いではなく、優秀な新人アシスタントとして扱う。条件を決めて、小さく頼んで、考えを言葉にする。（3項目）

- 3枚のカードを横に並べる。各カードに簡単なアイコン
- カード1「条件をはっきり」＝色・対象・文字数など、決めたことを具体的に伝える（鍵のアイコン）
- カード2「小さく頼んで重ねる」＝一度に全部ではなく、1つずつ頼んで直していく（階段のアイコン）
- カード3「考えを言葉にする」＝頭の中のイメージを、短い日本語で書き出す（吹き出しのアイコン）
- 上に「優秀な新人アシスタントとして接する」という短い見出し

---

## 図8 LPづくりのあとに広がる、4つの活用

**ねらい:** LPづくりはゴールではなく、AIとの対話に慣れる練習。同じ「投げる→見る→直す」で、仕事のいろいろな場面に広げられる。（構造・放射）

- 中央に「LPづくりで身につけた対話の型」を表す円を置く
- 円から4方向へ矢印を伸ばして、4つの活用を配置する
- 活用1「ビジネスモデルを考え直す」＝強み・弱み・競合・市場を整理する
- 活用2「競合リサーチを任せる」＝競合サイトを巡回して特徴を一覧にする
- 活用3「くり返し作業を自動化」＝毎日の作業を1本、運用までつなげる
- 活用4「LPを公開して反応を見る」＝無料で公開し、反応をもとに改善する
- 下に小さく「明日から、1つだけ Claude Code に任せてみよう」
